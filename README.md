# PropAgent Pro - 智能房地產 CRM 系統

## 項目概述
PropAgent Pro 是一個功能完整的房地產客戶關係管理系統，采用 React + Node.js + MongoDB 技術棧。

## 主要功能
- 客戶管理系統
- 房產信息管理  
- 數據分析儀表板
- 文檔上傳管理
- 通知系統
- 備份恢復功能

## 快速開始
```bash
# 後端啟動
cd backend && npm install && npm run dev

# 前端啟動  
cd frontend && npm install && npm run dev
```

- Backend: Node.js + Express + MongoDB
